# Izba · odprta vprašanja

Kaj mora vedeti gostitelj, preden naroči. Pod vsako vprašanje vpiši odgovor; ko je potrjen, ga prenesemo na `src/pages/izba/index.astro` ali v `src/izba.ts`.

**P1** = brez tega ni prodaje · **P2** = gradi zaupanje · **P3** = dopolnitev.

## 1. Cena in plačilo

- [x] **P1** Ali so cene (349 € / 499 € / 60 €) z DDV ali brez? Je Kompozitor zavezanec za DDV?
  - Odgovor: Kompozitor bo s.p. pod pragom 60.000 € letnega prometa, zato ni zavezanec za DDV. Cene so končne. Na računu: »DDV ni obračunan na podlagi 1. odstavka 94. člena ZDDV-1.« Potrdi z računovodjo. ✅

- [x] **P1** Ali se letni strošek (60 €) plača že prvo leto ob izdelavi ali šele od drugega leta?
  - Odgovor: Ob objavi. Prvo leto = izdelava + 60 € (npr. 349 € + 60 € = 409 €). ✅

- [x] **P2** Kaj pomeni »Obsežnejša predstavitev – po dogovoru«? Od kod se začne (št. enot, jezikov, strani)? Okvirna spodnja meja?

- [x] **P2** Kakšna je cena dela zunaj vključenega obsega (urna postavka ali fiksne postavke)?
  - Odgovor: Brez urne postavke. Za vsako zahtevo pošljemo fiksno ponudbo v potrditev pred izvedbo. ✅
